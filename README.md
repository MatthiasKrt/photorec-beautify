# Photorec Beautify

## Description

This Python script processes files recovered by Photorec, sorting them into a structured directory based on file type, year, and month. It attempts to rename files using metadata (such as EXIF data for images) or falls back to the file's creation date if no metadata is available.

## Why This Script is Useful

Photorec is an excellent tool for recovering lost files, but it restores them with generic names and a flat directory structure, making it difficult to manage the recovered data. This script solves these problems by:

- Organizing files into a structured directory for better accessibility
- Renaming files based on metadata, making identification easier
- Improving workflow efficiency by reducing manual sorting efforts
- Preventing file overwrites by ensuring unique filenames

## Features

- Sorts recovered files into directories based on:
  - File type (e.g., image, video, audio, etc.)
  - Year
  - Month
- Renames files based on:
  - EXIF metadata (for images, if available)
  - Creation date as a fallback
- Copies files to the destination instead of moving them
- Excludes report.xml files generated by Photorec to avoid unnecessary sorting

## Prerequisites

### Required Dependencies

Ensure you have Python installed. The script requires the following Python module:

- `exifread` (for reading EXIF metadata from images)

You can install it using pip:

```sh
pip install exifread
```

## Usage

### Running the Script

```sh
python script.py <input_directory> <output_directory>
```

- `<input_directory>`: Path to the directory containing Photorec-recovered files
- `<output_directory>`: Path to the directory where sorted files will be saved

### Example

```sh
python script.py ./photorec_output ./sorted_photorec
```

This will:

1. Read files from `./photorec_output`
2. Sort them into `./sorted_photorec` with the following structure:
   ```
   sorted_photorec/
     ├── image/
     │   ├── 2023/
     │   │   ├── 06/
     │   │   │   ├── 2023-06-15_12-30-45.jpg
     │   │   │   ├── 2023-06-20_14-22-10.png
     │   ├── 2024/
     │       ├── 01/
     │       │   ├── 2024-01-05_10-15-30.jpg
     ├── video/
     │   ├── 2023/
     │   │   ├── 07/
     │   │   │   ├── 2023-07-12_08-45-20.mp4
     ├── audio/
   ```

## Error Handling

- If `exifread` is not installed, the script will warn the user and fall back to using file creation dates.
- If incorrect arguments are provided, it will display a usage message and exit.
